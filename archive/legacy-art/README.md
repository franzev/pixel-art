# Legacy Art Quarantine

This directory contains legacy images moved from the former root category
folders during the repository cleanup on 2026-07-30.

These files are preserved because they are not byte-identical to the current
catalog and cannot be safely deleted in bulk. Their presence here does not make
them active, approved, retained, canonical, or valid positive references.

Classify each file before moving or deleting it:

- Active or retained render → `public/art/<category>/<collection>/`
- Intentional visual reference → `samples/<reference-family>/`
- Review or comparison artifact → `art-catalog/review-sheets/`
- Confirmed obsolete or deleted work → remove through the review workflow

Do not generate new work into this directory.
