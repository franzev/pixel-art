# Redo Wave 03 — Internal Evaluation

Date: 2026-07-30

Status: Internal gate complete. Twenty candidates are staged; nothing in this
file is user approval.

## Method

- Twenty passing candidates, produced from thirty-one fresh generations;
  never edits of rejected images.
- Four original generation waves of five, followed by targeted fresh
  replacements for failed slots.
- Every output stays outside `public/art/` until it passes.
- Every original defect, feedback note, and `nextAttempt` instruction receives a
  separate PASS or FAIL.
- Any uncertainty in hands, fingers, proportions, equipment construction,
  attachment, straightness, or effect removal is a FAIL.
- Full render with focused anatomy/equipment zoom and a 256-pixel view are
  required.
- Only PASS candidates enter the review sheet.
