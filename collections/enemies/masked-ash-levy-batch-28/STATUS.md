## Direction

This collection interprets the request as a coherent enemy-soldier family:
adult possessed humanoids whose faces are hidden by wearable dirty-ivory
theatre masks. The supplied mask sheet is a visual reference only for broad,
readable emotional cutouts. The retained Rootfoot Ghoul is a second visual
reference only for adult proportions, weathered materials, grounded menace,
pixel clustering, and small-scale readability.

The first five masks express joy, sorrow, anger, alarm, and numbness. Family
cohesion comes from the masks, soot-dark military work clothing, muted local
materials, and a shared screen-left presentation. Diversity comes from encounter
role, posture, silhouette anchor, equipment, garment construction, negative
space, and movement implication.

All assets remain drafts. Do not create a retained manifest, promote the files,
update the enemy lore compendium, or change canonical counts until the user
explicitly approves individual designs.
