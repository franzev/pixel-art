## Shared direction

Use case: `stylized-concept`

Asset type: unapproved native-looking enemy sprite concept for a 2D gothic
Metroidvania, Spanish colonial Philippines circa 1896–1898.

Create exactly one complete adult soldier per square source. Draw genuine

selective highlights. The intended native construction should read at roughly
58–78 visible pixels high depending on pose and match the Crimson Knight's adult

feet. Never duplicate weapons, fingers, straps, or equipment. Keep all anatomy,

medieval swords, oversized heads, propaganda poses, flags, excessive medals,
