# Faceless Highschoolers Batch 26 — Generation Prompts

**Prepared:** 2026-07-30  
**Workflow:** Built-in image generation; one fresh call per design  
**Status:** Three-design draft review wave

## Interpretation and reference

Create three separate faceless Filipino high-schooler concepts set in 2026 for
the Ashen Provinces. They are contemporary supernatural students rather than
historical figures or real people.

The closest accepted project direction is the restrained isolated humanoid
treatment used by the core enemies: one readable role, one coherent clothing
system, complete silhouette, connected pixel clusters, broad value masses, and
a plain warm near-black background. Do not copy an existing character's pose,
costume, anatomy, prop arrangement, or silhouette.
