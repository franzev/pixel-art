# Evil-Green Spectral Foot Soldiers — Status

## Goal

Create five ghost foot soldiers using the supplied washerwoman ghost as the
positive visual reference for spectral translucency, layered shading, bright
rim light, and trailing wisps.

User locks for this pass:

- Concept 1 has a horrifying visible human apparition-face.
- Concepts 2–5 have exposed spectral skulls.
- Only exposed body parts and their wisps are bright evil green.
- Armor, clothing, leather, weapons, shields, boots, poles, and banners remain
  opaque, solid, physical materials.
